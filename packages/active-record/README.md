# @forestfuture/active-record

A Rails-inspired Active Record for Cloudflare Workers: Models, Relations, validations, callbacks and associations, with an adapter for each database. Install it with an adapter, such as [`@forestfuture/d1-record`](https://www.npmjs.com/package/@forestfuture/d1-record) for Cloudflare D1.

The guide is at [d1-record.forestfuture.dev](https://d1-record.forestfuture.dev), and the source is on [GitHub](https://github.com/forestfuture/d1-record).
