# @forestfuture/active-record

## 0.6.0

### Minor Changes

- [#281](https://github.com/forestfuture/active-record/pull/281) [`febbe8c`](https://github.com/forestfuture/active-record/commit/febbe8c7e7090c6ecf5da4ba97f8eca5d09b6f2a) Thanks [@christopherstyles](https://github.com/christopherstyles)! - The command line is now `active-record`, also installed as `ffar`, and comes with `@forestfuture/active-record`. `npx d1-record` is gone: run `npx active-record schema`, `g model`, `g migration` and `console` as before.

  - `npx active-record migrate` applies your pending migrations, locally by default, through your project's own Wrangler. `--remote` asks you to type the database's name first, and `--yes` skips that. The generators now suggest it as the next step.
  - The command finds its adapter from your `package.json`. When a project has several installed, choose one with `--adapter d1`.
  - Generated schema files now say "Generated by `active-record schema`". Their format number went up, so `active-record schema --check` asks you to regenerate them once.

- [#280](https://github.com/forestfuture/active-record/pull/280) [`41a4c37`](https://github.com/forestfuture/active-record/commit/41a4c37ff3d12b61a1d5ee0b13f68ede01805631) Thanks [@christopherstyles](https://github.com/christopherstyles)! - The library is now two packages, both breaking changes. `@forestfuture/active-record` is the core, and `@forestfuture/d1-record` is its D1 adapter. Install both. The guide's [Upgrading to 0.6](https://d1-record.forestfuture.dev/upgrading) walks through the move.

  - Import Models, Relations, validations, callbacks, associations, `withDatabase`, `batch` and the error classes from `@forestfuture/active-record`. Import `connect`, `withSession`, `NoSession`, `d1`, and D1's `QueryEvent` and `QueryListener`, from `@forestfuture/d1-record`. `d1-record` re-exports nothing of the core.
  - The generated schema names its adapter: `adapter: d1({ binding: "DB" })` replaces `binding: "DB"`. Run `npx active-record schema` to regenerate it.
  - `toSql()` on a Model with no generated schema, outside `withDatabase` and with no `db`, throws `NoDatabase`, since nothing says which database's SQL to write.
  - The agent skill is now `active-record`, in `@forestfuture/active-record`, which ships `llms-full.txt` too.

The core was part of `@forestfuture/d1-record` before 0.6: its history up to 0.5 is in [`packages/d1-record/CHANGELOG.md`](../d1-record/CHANGELOG.md).
