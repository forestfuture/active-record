# @forestfuture/d1-record

The Cloudflare D1 adapter for [`@forestfuture/active-record`](https://www.npmjs.com/package/@forestfuture/active-record): `connect`, `withSession` and the `d1-record` command. Install both packages.

The guide is at [d1-record.forestfuture.dev](https://d1-record.forestfuture.dev), and the source is on [GitHub](https://github.com/forestfuture/d1-record).
