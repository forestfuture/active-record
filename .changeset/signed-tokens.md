Sign tokens with the Worker's secret (#517). `await user.signedId({ purpose, expiresIn })` signs a record's id, and `User.findSigned(signedId, { purpose })` finds it again. `this.generatesTokenFor("emailConfirmation", { expiresIn: { days: 1 }, dependsOn: (user) => user.email })` in `static {}` declares tokens for a purpose: `await user.generateTokenFor(purpose)` makes one, and `User.findByTokenFor(purpose, token)` finds its record until it expires or the value it depends on changes. A secure password gets a reset token, `await user.passwordResetToken()`, found with `User.findByPasswordResetToken(token)`: it lasts 15 minutes and stops working once the password changes (`securePassword: { resetToken: false }` leaves it out). The finders are Relation methods too, keeping conditions and default scopes, and each has an `OrThrow` that throws the new `InvalidToken` for a token that isn't valid. Tokens are signed with HMAC-SHA256 under the Worker's `SECRET_KEY_BASE`, or what a Model's `static signingSecret(env, database)` returns: a list to rotate secrets, or a secret per tenant's database.
