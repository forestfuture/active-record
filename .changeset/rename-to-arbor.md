The library is now Arbor ORM, published as `@forestfuture/arbor`; `@forestfuture/active-record` gets no new versions. Install `@forestfuture/arbor`, and import from it (and its `/d1`, `/postgresql`, `/adapter` and `/cli` entries) in place of `@forestfuture/active-record`. The command is `arbor` (`npx arbor schema`), and `active-record` and `ffar` are gone. It reads `arbor.jsonc`, so rename `active-record.jsonc` and point its `$schema` at `./node_modules/@forestfuture/arbor/config-schema.json`. `ActiveRecordError` is now `ArborError`. Generated schemas say "Generated by `arbor schema`", so `arbor schema --check` asks you to run `npx arbor schema` once. The console keeps its history in `arbor-history`, and on Postgres the command keeps its files in `node_modules/.cache/arbor`; the old ones aren't read. The agent skill is `arbor` (`npx skills add forestfuture/arbor`), and the guide is at https://arbor.forestfuture.dev. See https://arbor.forestfuture.dev/upgrading.
