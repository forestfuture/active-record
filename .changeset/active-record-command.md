The command line is now `active-record`, also installed as `ffar`, and comes with `@forestfuture/active-record`. `npx d1-record` is gone: run `npx active-record schema`, `g model`, `g migration` and `console` as before.

- `npx active-record migrate` applies your pending migrations, locally by default, through your project's own Wrangler. `--remote` asks you to type the database's name first, and `--yes` skips that. The generators now suggest it as the next step.
- The command finds its adapter from your `package.json`. When a project has several installed, choose one with `--adapter d1`.
- Generated schema files now say "Generated by `active-record schema`". Their format number went up, so `active-record schema --check` asks you to regenerate them once.
